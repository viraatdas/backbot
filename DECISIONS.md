# Decisions

Shared, agent-authored log of cross-cutting decisions the fleet must honor. The conductor records plan/rebase/steer decisions here; workers record interface contracts + adjustments. Each entry is a `##` heading with **What / Why / By** so it scans. Re-read before each significant step; jj merges concurrent edits as first-class conflicts on fan-in.

## worker: BackbotBar is now a real macOS Login Item (SMAppService)
- **Did:** BackbotBar is now a real macOS Login Item (SMAppService) with a custom logo, replacing the launchd autostart agent that showed up as an anonymous background executable with no icon. Added menubar/BackbotMark.swift: one Core Graphics vector (a minimal bot head - rounded square, two eyes, antenna dot echoing the site brand mark) that feeds BOTH the menu bar glyph and the app icon, so they cannot drift. menubar/MakeIcon.swift renders it into an .iconset at build time and build.sh pipes that through iconutil into Contents/Resources/AppIcon.icns - no binary artwork in the repo. Menu bar states are badge variants of the same mark: plain, checkmark, red cross, and a rotating arc while a backup runs. Key finding, established experimentally: macOS 26 frames legacy icons in a light system tile only when the art has transparent margins; fully opaque edge-to-edge art gets masked into the proper shape instead. Compiling an Assets.car via actool made no difference - alpha was the deciding factor - so the icon art is now a full-bleed opaque square. Also added AssociatedBundleIdentifiers to com.backbot.nightly.plist so the nightly CLI agent stops rendering as an unidentified-developer exec row. Verified live: Login Items shows a BackbotBar row with the logo, the menu bar shows the bot glyph with its checkmark badge, exactly one instance runs, and the old launchd agent is gone.
- **Interfaces:** menubar/BackbotMark.swift - BackbotMark.statusImage(pointSize:badge:) -> template NSImage for NSStatusItem; BackbotMark.appIcon(px:) -> CGImage for one icns slot; BackbotMark.markImage(px:badge:stroke:filled:color:) -> mark on its own transparent layer; BackbotBadge enum {none, ok, failed, running(phase:)}. menubar/MakeIcon.swift - 'makeicon <output.iconset>' CLI rendering all 10 icns slots. BackbotBar --register-login-item / --unregister-login-item - headless login item management used by install.sh and uninstall.sh; both exit before the single-instance guard so they never disturb a running copy. menubar/build.sh [output-dir] - now also generates the icon and runs lsregister; targets macos13 (SMAppService minimum), bundle version 1.1.
- **Delivery:** verified; macos-app; target=BackbotBar.app menu bar agent, installed and registered as a Login Item; revision=cccf6e1 plus uncommitted working-tree changes; verifiedAt=2026-08-16T08:51:51Z; checks=9
- **By:** worker · 2026-08-16T08:53:51.370Z
